连接 GitHub

面板通过 GitHub API 直接读写仓库配置，所有操作在你自己的浏览器里完成，不经任何第三方服务器。
Token 只保存在本机浏览器 localStorage。
推荐 Fine-grained token（github.com → Settings → Developer settings → Fine-grained tokens）：仅授权本仓库，权限勾 Actions、Secrets、Variables、Workflows、Contents 均为 Read and write（后两项用于面板修改签到时间），有效期设 90 天。

自动签到平台

开关写入仓库 Variable CHECKIN_PLATFORMS，每天北京时间 9:00 定时执行。至少开启一个。

签到时间

GitHub 的定时规则写在工作流文件的 cron 里（GitHub 不支持用 Variables 之类的配置参数化 cron），保存时面板会自动改写该文件并提交到仓库，无需手动编辑。自动附带 +20 分钟备用触发，防 GitHub 高峰期延迟漏跑；签到幂等，重复执行无害。当前生效：—
